YOUR WORKSPACE / EXTENSIONS

Commands, your way.

CuteTerm runs real PowerShell. Add a .ps1 file to your personal commands folder, then type ct-reload to make it available as a command.

01 Make your own command PowerShell

Save this as greet.ps1 in your commands folder:

param([string]$Name = "friend")
Write-Host "hello, $Name ✦" -ForegroundColor Magenta

In CuteTerm type ct-reload, then greet Tai. Your script runs inside a real PowerShell session.

About the 355+ command goal

CuteTerm exposes the complete native PowerShell command catalog, including cmdlets, functions, aliases and installed tools. Run ct-count to see the real count on your PC. Custom scripts extend that catalog.

Meet CuteTerm.

A modern Windows terminal with a real ConPTY backend, built in C# with WebView2 and xterm.js. No Electron, no pretend command execution.

VERSION0.2.0
PLATFORMWindows 11
ENGINEConPTY + xterm.js

Open source project repository: taithedev/Cuteterm. Custom scripts execute with your account permissions. Only run scripts you trust.
